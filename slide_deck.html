How We Got Here

Methodology

  • 🌐
    Data Source: Glassdoor salary pages for "Veterinarian" in Boston, MA and Raleigh, NC.
  • 🤖
    Scraper: Python script using requests (with optional Playwright browser automation) + BeautifulSoup / JSON-LD extraction.
  • 📊
    Parsing: Three-tier strategy — structured CSS class rows → JSON-LD schema.org objects → generic dollar-amount fallback.
  • 💾
    Output: Records saved as timestamped CSV (output/vet_salaries_YYYYMMDD_HHMMSS.csv).
  • ⚠️
    Limitations: Self-reported salaries may have selection bias; Glassdoor may throttle or block automated requests.
